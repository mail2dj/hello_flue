# Flue로 쉽게 만드는 실전 AI 에이전트

TypeScript 기반 AI 에이전트 프레임워크 **Flue** 강의 레포지토리입니다. React 개발자를 위한 강의로, 원하는 LLM 프로바이더를 골라 AI 에이전트를 만들고, 설정하고, 배포하는 방법을 배웁니다.

👉 [nomadcoders.co/flue-framework](https://nomadcoders.co/flue-framework)

## 강의는 단독 구매할 수 있나요?

본 강의는 AX School 멤버십에 포함된 강의이며, 단독 구매는 불가합니다.

## 강의는 어떻게 구성되어 있나요?

이해 → 스펙 작성 → 계획 → 구현 → 검증 → 리뷰 → 배포까지, 실제 프로젝트 워크플로우 전체를 따라갑니다. 모델 연동, 툴, 상태 관리, 그리고 Cloudflare Workers 배포까지 다룹니다.

## 수강에 필요한 사전 지식이 있나요?

TypeScript와 React 코드를 읽고, 기본적인 HTTP와 터미널 명령어를 사용할 수 있다면 수강 가능합니다. 에이전트 프레임워크나 Cloudflare 경험은 필요하지 않습니다.

## 코딩을 전혀 모르는 왕초보도 들을 수 있나요?

아니요. 이 강의는 기초 코딩 지식이 있는 개발자를 대상으로 하며, 프로그래밍 입문자용 강의가 아닙니다.

## AI 구독이 필요한가요?

Flue는 오픈소스지만, 실습 과정에서 모델 프로바이더의 API 사용료가 발생할 수 있습니다.

## 수강 기간은 어떻게 되나요?

멤버십 기간인 1년 동안 언제든지 무제한 반복 수강이 가능합니다.

## 수강 중 질문은 어떻게 하나요?

강의 내 댓글/이슈 기능을 이용하거나, 멤버 전용 커뮤니티에서 질문하고 다른 수강생들과 피드백을 주고받을 수 있습니다.
