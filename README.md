# Flue로 쉽게 만드는 실전 AI 에이전트

**React 개발자를 위한 TypeScript AI 에이전트 프레임워크**

하나의 프레임워크로 AI 에이전트를 만들고, 원하는 LLM을 연결해 배포합니다.

👉 [nomadcoders.co/flue-framework](https://nomadcoders.co/flue-framework)

## 하네스는 Flue에 맡기고, 에이전트의 행동을 설계합니다

Flue가 제공하는 Pi 기반 하네스 위에서, 필요한 도구와 실행 환경을 갖춘 에이전트를 만듭니다.

React 개발자에게 익숙한 방식으로 에이전트를 만들고, 원하는 LLM과 배포 환경을 자유롭게 선택합니다.

## 강의는 어떻게 구성되어 있나요?

이해 → 스펙 작성 → 계획 → 구현 → 검증 → 리뷰 → 배포까지, 실제 프로젝트 워크플로우 전체를 따라갑니다. 모델 연동, 툴, 상태 관리, 그리고 Cloudflare Workers 배포까지 다룹니다.

## 수강에 필요한 사전 지식이 있나요?

TypeScript와 React 코드를 읽고, 기본적인 HTTP와 터미널 명령어를 사용할 수 있다면 수강 가능합니다. 에이전트 프레임워크나 Cloudflare 경험은 필요하지 않습니다.
